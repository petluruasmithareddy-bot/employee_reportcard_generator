#  Contact Book Application

A simple and efficient Contact Book application built using Python.  
This project allows users to manage contacts by adding, viewing, searching, and deleting contact details, with data stored persistently in a text file.

##  Project Overview

The Contact Book is a menu-driven application designed to simulate a real-world contact management system.  
It helps users organize and access contact information easily through a command-line interface.

##  Features

-  Add new contacts  
-  View all saved contacts  
-  Search contact by name  
-  Delete contact  
-  Persistent storage using text file  
-  User-friendly menu-driven interface  

## Technologies Used

- *Python**   
- **File Handling (Text Files)**
